# /kz-company-setup — регистрация бизнеса в РК

Перед ответом прочитать [../../references/kz-law-sources.md](../../references/kz-law-sources.md) и соблюдать правило «проверять, а не вспоминать»: каждую норму, ставку и срок сверять через веб-поиск с adilet.zan.kz и указывать дату проверки.

**Важно**: навык помогает в юридической работе, но не заменяет консультацию юриста РК. Выводы для подписания, регистрации, споров и крупных сумм — передавать юристу.

## Шаг 1. Выбор формы (сравнить на актуальных данных)
| Критерий | ИП | ТОО | Частная компания МФЦА |
|---|---|---|---|
| Сколько владельцев | один | один и более | один и более |
| Ответственность | всем имуществом | в пределах вклада | в пределах вклада |
| Налоговые режимы | спец. режимы для ИП | общий / спец. режимы для юрлиц | по правилам МФЦА + НК РК |
| Для инвесторов | не подходит | возможно | удобнее (английское право) |
| Партнёры и доли | нельзя | можно | можно, гибче |
Для команды из нескольких учредителей по умолчанию — ТОО или МФЦА; ИП только для временного старта одного человека (с письменной договорённостью, кому принадлежит бизнес).

## Шаг 2. Регистрация (проверить актуальный порядок на egov.kz)
- ТОО: онлайн через egov.kz по типовому уставу или с собственным уставом; ЭЦП учредителей; юридический адрес; уставный капитал.
- МФЦА: через портал МФЦА (aifc.kz), требования и сборы — уточнить.
- Сразу решить: кто директор (его личная ответственность), кто держит ЭЦП компании.

## Шаг 3. После регистрации
- Банковский счёт, Kaspi Business/эквайринг; правила подписи (двойная подпись).
- Налоговый режим: выбрать в срок (подробно — /kz-tax-check); постановка на учёт по НДС при превышении порога.
- ККМ онлайн при приёме наличных/карт от физлиц.
- Уведомления/лицензии по виду деятельности (/kz-compliance-check).
- Первые сотрудники: трудовые договоры, отчисления (/kz-labor-law).
- Документы учредителей: соглашение учредителей (/kz-founders-agreement), передача прав на наработки компании.

## Шаг 4. Astana Hub (если IT)
- Проверить на astanahub.com: перечень приоритетных видов деятельности, условия (доля дохода от приоритетной деятельности, договор присоединения), что даёт участие по НК РК 2026, как не потерять статус.
- Предупредить: льготы только на доход от реальной IT-деятельности; схемы «прогона» оборота — риск лишения статуса и доначислений.
