# Legal KZ

Юридический помощник по законам Республики Казахстан для небольшой команды учредителей. Сделан на основе плагина Legal (Anthropic) и переделан под право РК.

## Навыки
| Навык | Для чего |
|---|---|
| /kz-brief | Справка по юридическому вопросу или срочной ситуации |
| /kz-risk-assessment | Оценка рисков по матрице «тяжесть × вероятность» |
| /kz-review-contract | Проверка договора по ГК РК, правки и позиция на переговорах |
| /kz-compliance-check | Законно ли запускать идею: лицензии, уведомления, запреты |
| /kz-triage-nda | Экспресс-проверка NDA |
| /kz-meeting-briefing | Бриф к встрече и итоги |
| /kz-founders-agreement | Анкета и соглашение учредителей (ТОО РК / МФЦА) |
| /kz-company-setup | Регистрация ИП/ТОО/МФЦА, Astana Hub, первые шаги |
| /kz-tax-check | Налоги по НК РК 2026 |
| /kz-labor-law | Найм и трудовые отношения по ТК РК |

## Главное правило
Каждая норма, ставка и срок проверяются через поиск по первоисточнику (adilet.zan.kz, egov.kz, kgd.gov.kz) с датой проверки. Справочник: `references/kz-law-sources.md`.

## Ограничения
Плагин помогает в юридической работе, но не заменяет юриста. Для подписания, регистрации, споров и крупных сумм — консультация юриста РК.
