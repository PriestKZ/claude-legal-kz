# /kz-meeting-briefing — бриф к встрече

Перед ответом прочитать [../../references/kz-law-sources.md](../../references/kz-law-sources.md) и соблюдать правило «проверять, а не вспоминать»: каждую норму, ставку и срок сверять через веб-поиск с adilet.zan.kz и указывать дату проверки.

**Важно**: навык помогает в юридической работе, но не заменяет консультацию юриста РК. Выводы для подписания, регистрации, споров и крупных сумм — передавать юристу.

## До встречи
1. Уточнить: тип встречи (учредители, инвестор, партнёр/поставщик, госорган/акимат, банк), участники, цель, что уже обсуждалось.
2. Собрать контекст из доступных источников (документы проекта, переписка, предыдущие заметки).
3. Для юридических тем — короткая проверка норм (см. справочник).

### Формат брифа
```
## Бриф: [встреча] — [дата]
### Цель и желаемый результат
### Участники и их интересы
### Контекст (что уже решено, что нет)
### Юридические моменты (с источниками)
### Наши позиции: обязательно / можно уступить / красные линии
### Вопросы, которые задать
### Решения, которые нужно принять на встрече
### Чего не хватает для подготовки
```

## Для встреч разного типа
- **Учредители**: сверять с анкетой/соглашением учредителей; фиксировать расхождения во мнениях дословно.
- **Инвестор**: оценка, доля, права инвестора (вето, ликвидационные преференции, drag/tag-along), где регистрироваться (ТОО РК или МФЦА).
- **Госорган/акимат**: правовое основание запроса, что можно не предоставлять, кто подписывает.
- **Партнёр/поставщик**: условия договора (см. /kz-review-contract), NDA до раскрытия информации.

## После встречи
```
## Итоги: [встреча] — [дата]
### Решения (кто согласился, дословно)
### Задачи
| Задача | Ответственный | Срок | Статус |
### Открытые вопросы
```
Напоминать: решение учредителей, влияющее на деньги или доли, оформляется письменным протоколом.
